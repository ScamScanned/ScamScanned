Install — Alpha

Four steps. No command line.

During the Alpha the extension installs straight from a download rather than the Chrome Web Store. Works on a standard Chrome or Edge browser on Windows or macOS.

Running in about a minute

Download for Chrome — v0.2.2 (ZIP)
  1. Find scamscanned-alpha-v0.2.2.zip in Downloads, right-click it and choose Extract All… (macOS: double-click).
  2. Type chrome://extensions into the address bar.
  3. Switch on Developer mode — the toggle in the top-right corner.
  4. Click Load unpacked, pick the extracted folder, then pin the shield with the puzzle-piece icon.

Full walkthrough, updating and troubleshooting: the install guide

Why isn’t it in the Chrome Web Store yet?

The Alpha installs by hand while the store review requirements are being finished — the store listing is the next milestone, and it turns this into a one-click install with automatic updates.

Side-loaded extensions can show a small Chrome reminder after a restart. That is normal for a manual install; installing the store version later avoids it.

What it detects

The patterns behind risky listings, spelled out.

Risky listings reuse the same handful of plays. ScamScanned watches for the concrete ones — the phrases and page states that matter before checkout.

Shipping windows that outlast refunds

A long delivery window can push you past the marketplace’s dispute deadline before the item arrives. The banner flags the window; check the date before you pay.

Delivery in 4–6 weeks Ships from overseas

Seller-name shape signals

Some storefronts use generated-looking names — garbled strings, all-caps text, or very short histories. These are weak signals, not proof; the banner shows them next to the seller’s printed record.

BEST_DEAL_STORE_2024X ALL-CAPS STOREFRONT

Checkout outside the normal flow

When the standard buy box is missing, checkout can route through a secondary seller offer. That path may sit outside the marketplace’s normal refund and dispute process.

No featured offer available See all buying options

Discounts that rush the decision

A very deep markdown can make a listing look like a bargain before you compare. The banner flags the markdown; treat it as a prompt to check the reference price and the seller.

was $499.99, now $89.99 82% off — today only

How it works

Three steps. Zero configuration.

No accounts, no dashboards, nothing to tune. Install it once and it quietly does its job.

  1. 01

    Runs locally in your browser

    Flagging is computed on your device. On Amazon and Walmart, when a warning banner actually fires, one anonymous diagnostic — the listing address, page title, and seller name — is sent so the banner can build its alternative-search link and check the public enforcement-record list. eBay, Etsy, Craigslist and Facebook scans send nothing.

  2. 02

    Scans each page as you shop

    When a product page loads, ScamScanned checks the printed page on the spot — shipping terms, seller record, checkout shape, and pricing.

  3. 03

    Shows a warning before checkout

    If a listing trips the signals, a banner appears and names each reason. What you do with the warning is entirely your call.
